1. `packages/companion/tests/test_companion_drive.py::test_a_hung_helper_is_killed_at_its_timeout` and `::test_a_cancelled_call_kills_the_helper` — `AssertionError: assert False, where False = gone(<pid>)`. Cause, reproduced outside pytest (`scratchpad/p10/zombie_repro.py`): the test's `FakeDesktop` answers `drive_cancel` with `proc.terminate()`, then `gone()` polls `os.kill(pid, 0)` in a blocking `time.sleep` loop for 2 s; on this host Python 3.12.3 uses `PidfdChildWatcher` (`asyncio.unix_events.can_use_pidfd()` is `True`), which reaps only when the event loop runs, so the terminated child stays a zombie (`ps -o stat` = `Z`) and `os.kill(pid, 0)` keeps succeeding; it is reaped the moment the loop runs again (`returncode -15`). A main-side fix (reap in `gone()` by awaiting the fake desktop's process, or poll `proc.returncode`) belongs to SOLUSDEV-319, not to this branch; main's code is not touched here.
