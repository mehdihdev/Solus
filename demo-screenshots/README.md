## Capture context

The CAD view is static geometry beside live telemetry; it does not demonstrate live joint animation. Playback uses an existing recorded run. The BOM listing is published and available to install, but is not installed in this demo workspace. Firmware compilation succeeded; uploading to the Uno is a separate manual step.

These browser-renderer captures show desktop-only notices for native file grants and device discovery. The Home screen includes actual account information, test projects, and an Onshape quota warning. Billing shows local development credits and is a supporting capture, not a public pricing reference. No extra provider syncs or hardware commands were run to stage these images.
